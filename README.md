# 🤖 AI Chat Assistant

An AI-powered chat application built using **Python, Streamlit, Gemini API, and Google GenAI SDK**.

The application allows users to interact with an AI assistant, maintain conversation history, use custom system instructions, and clear the conversation when needed.

---

## 📌 Project Overview

This project demonstrates how to integrate a Large Language Model (LLM) API into a Python application.

The application provides a simple and user-friendly chat interface where users can:

- Send messages to an AI assistant
- Receive AI-generated responses
- Maintain conversation history
- Use custom system instructions
- Clear the conversation
- Handle API errors gracefully

---

## 🛠️ Technologies Used

- **Python**
- **Streamlit**
- **Google Gemini API**
- **Google GenAI SDK**
- **python-dotenv**
- **Git & GitHub**
